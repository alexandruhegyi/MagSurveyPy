Magnetic profile

Profile tool ready
Draw a multi-vertex line and finish with a double-click, Enter, or the Finish action beside the map drawing tool. Drawing stops immediately after completion. Use Edit profile to move vertices, then Save profile to resample the graph.

Raster inspection

Select a raster in the Layers panel to see its data range, mean, standard deviation, CRS, dimensions and display stretch in the Properties drawer.

Raster georeferencer

For an unreferenced total-field/fluxgate raster, open the zoomable image editor, pan/zoom and click 3 or more known locations at continuous sub-pixel precision, then enter their GPS/map coordinates. MagSurveyPy fits one affine transform from all points, reports residuals, and writes a new quantitative GeoTIFF under Results/GEOREFERENCED. Magnetic values are copied unchanged.

Recommended control points

Use at least 3 non-collinear points, preferably 4–8 points distributed around the survey perimeter. More well-distributed GPS control points make the residual statistics meaningful. Use EPSG:4326 for longitude/latitude or your survey UTM EPSG for Easting/Northing.

After georeferencing

The new raster is added immediately as a normal Web GIS layer. For another projection use export reproject; the georeferencing control points and QC recipe remain stored beside the GeoTIFF.

Drawing editor

Drawing tools ready
No drawing selected
Click once to select; double-click to edit. Delete removes only this selected feature.
This editor uses Leaflet-Geoman instead of Leaflet.Draw. Create one feature at a time; line/polygon creation finishes by double-click, Enter, or the map toolbar Finish action and then exits automatically. Click a finished feature once to select it or double-click it to edit immediately. Edit selected exposes handles only for that feature; Save geometry or Enter commits it. Escape or Cancel active tool reverts an unfinished edit. Delete removes only the selected feature.
