# MagSurveyPy v1.0.2 — documentation and metadata maintenance

MagSurveyPy v1.0.2 is a documentation and metadata maintenance release.

No scientific processing algorithms, numerical defaults, interpolation mathematics, filtering mathematics, georeferencing, native data decoding, or quantitative GIS behaviour are intentionally changed relative to v1.0.1.

Changes in v1.0.2 include:

- updated and expanded README presentation;
- final scientific workflow figures from the MagSurveyPy preprint;
- PyPI-compatible absolute image references;
- dynamic PyPI version badge with reduced cache duration;
- refreshed version and citation metadata;
- consistent v1.0.2 identification in the application, documentation, and local GIS interface.

Scientific description:

Hegyi, A. (2026). *MagSurveyPy: An Open-Source Framework for Archaeological Magnetometry Processing and Spatial Analysis* (Version 1). Zenodo.
