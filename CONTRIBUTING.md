# Contributing to MagSurveyPy

Contributions are welcome through GitHub issues and pull requests.

For code changes:

1. Create a branch from the current development branch.
2. Keep scientific changes separate from interface/documentation changes where possible.
3. Add or update a regression test when changing processing behavior.
4. Run `mspy --version`, `mspy --help`, and `mspy tools doctor` after installation.
5. Describe any change that can alter scientific output explicitly in the pull request.

Please avoid committing project datasets, generated results, environments, caches, or credentials.
